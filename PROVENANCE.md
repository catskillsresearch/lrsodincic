# Provenance

This repository is the substantive development of the LRSODInCIC
formalization (L/R/S/O/D axiom layers embedded in Lean 4's CIC). It is
not a thin wrapper and not a reimplementation of an independent
formalization.

The work began as a subdirectory of
[`catskillsresearch/scott_models`](https://github.com/catskillsresearch/scott_models)
at `LRSODInCIC/`. That parent repository is about Scott models and related
constructions. LRSODInCIC was parked there because it was convenient, not
because it belongs to that project.

This repository is the continuation of that directory: same author, same
license (Apache-2.0), same Lean development, moved to its own Lake package.
The old path is historical only. Further work belongs in
[`catskillsresearch/lrsodincic`](https://github.com/catskillsresearch/lrsodincic).
